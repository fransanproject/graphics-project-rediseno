# Graphics Project — concept redesign demo

Concept-only demo for thegraphicsproject.com. It does not touch the real Shopify site.

- Scroll-video hero (190 frames), collections carousel with autoplay
- Side menu with all original pages: Home, The Archive, About Us, Points of Sale, Contact
- Points of sale: 277 stores by autonomous community, with a real OpenStreetMap map (satellite view) that flies to the selected store and opens its balloon
- 5 languages, single HTML file

Live demo: https://fransanproject.github.io/graphics-project-rediseno/
